# APNG Studio

LINE 動態貼圖／アニメーションスタンプ用的排幀與匯出工具。

直接讀取繪圖軟體的原始檔：CLIP STUDIO PAINT（.clip）、Procreate（.procreate）、Photoshop 與 ibisPaint 等匯出的 PSD（.psd／.psb）、Krita（.kra）、MediBang Paint／FireAlpaca（.mdp）。把圖層拖進影格、即時預覽，依 LINE 驗證器的實際算法檢查幀數與秒數，匯出 APNG／GIF。

## 下載 ／ ダウンロード

到 [Releases](../../releases/latest) 下載最新版：

- `APNG-Studio-版本-setup.exe`：Windows 安裝版（會自動更新）／インストーラー版（自動アップデート対応）
- `APNG-Studio-版本-portable.exe`：Windows 免安裝版（不會自動更新，有新版時會通知）／ポータブル版（新しいバージョンの通知のみ）
